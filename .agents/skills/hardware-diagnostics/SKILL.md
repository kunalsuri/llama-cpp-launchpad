# Hardware Diagnostics Skill

This skill explains how hardware profiling operates in `llama-cpp-launchpad` and how to simulate or diagnose hardware detection across platforms.

## Architecture

Hardware detection is implemented entirely within `utils/hardware.py` using Python standard library tools:
- **RAM**: Reads `/proc/meminfo` on Linux, `sysctl hw.memsize` on macOS, and `GlobalMemoryStatusEx` via `ctypes` on Windows.
- **CPU**: Thread count via `os.cpu_count()`, processor marketing name via registry (Windows), `/proc/cpuinfo` (Linux), or `sysctl machdep.cpu.brand_string` (macOS).
- **GPU**: NVIDIA GPU name and total VRAM via `nvidia-smi` query, Apple Silicon unified memory via `platform.machine() == "arm64"`.
- **`llama.cpp` GPU Backend Usability**: Checks whether `llama-server --list-devices` reports CUDA, Vulkan, Metal, ROCm, HIP, or SYCL.

## Diagnostic Procedures

### 1. Print Current Hardware Profile to Console
```bash
python utils/hardware.py --print
```

Sample output:
```properties
# Generated by utils/hardware.py
HW_GENERATED_AT="2026-10-14T01:00:00+00:00"
HW_OS="Windows 11"
HW_ARCH="AMD64"
HW_CPU_NAME="AMD Ryzen 7 5800X"
HW_CPU_THREADS="16"
HW_RAM_MB="32486"
HW_GPU_KIND="nvidia"
HW_GPU_NAME="NVIDIA GeForce RTX 3060"
HW_VRAM_MB="12288"
HW_GPU_USABLE_BY_LLAMACPP="true"
HW_LLAMA_SERVER="C:\llama.cpp\llama-server.exe"
HW_RECOMMENDED_MODE="gpu"
HW_SIGNATURE="32486-12288-nvidia-1-16"
```

### 2. Generate `.hardware.env`
```bash
python utils/hardware.py
```
This writes `<project_root>/.hardware.env`. This file is git-ignored and contains hardware metrics without usernames, serial numbers, or network identifiers.

### 3. Simulating Hardware Overrides
For testing how Launchpad behaves on different hardware specs:

| Variable | Description | Example |
|----------|-------------|---------|
| `LP_RAM_MB` | Override system RAM in megabytes | `LP_RAM_MB=8192` (Simulate 8GB machine) |
| `LP_VRAM_MB` | Override GPU VRAM in megabytes | `LP_VRAM_MB=4096` (Simulate 4GB GPU) |
| `LP_GPU_USABLE` | Force llama.cpp GPU capability evaluation | `LP_GPU_USABLE=0` (Simulate CPU-only build) |
| `LLAMA_SERVER` | Path to llama-server binary | `LLAMA_SERVER=/custom/path/llama-server` |

PowerShell Example:
```powershell
$env:LP_RAM_MB = "16384"
$env:LP_VRAM_MB = "0"
python utils/hardware.py --print
```
